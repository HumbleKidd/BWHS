# BWHS clone app

Phone and Android TV shell for https://bwhs.online/clone/

- Mobile opens the clone site unchanged.
- Leanback opens the same clone site with D-pad focus, no layout changes.
- ExoPlayer is included for a direct media URL. Embed pages stay in the site player.

Build in Android Studio (SDK 35). This repo does not compile the APK on GitHub Pages.
